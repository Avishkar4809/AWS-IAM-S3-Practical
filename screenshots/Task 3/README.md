Task 3: Create a custom IAM policy

1. Create a customer-managed policy named CustomS3ReadPolicy.
2. The policy must allow listing your practical S3 bucket and reading objects in that bucket only.
3. The policy must not grant permission to upload, overwrite, or delete objects.
4. Attach the policy to the appropriate test user or group. Use your actual bucket ARN and object ARN in the policy.

Evidence to submit: Policy JSON and screenshot showing the policy attached to the user or group.
